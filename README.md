# MindSpace iOS — Public Distribution Source

This repository serves as the official **SideStore and AltStore community source** for [MindSpace iOS](https://github.com/vkr1729/mindspace-source).

## 🚀 How to Add to SideStore / AltStore

1. In SideStore / AltStore on your iOS device, navigate to **Sources**.
2. Tap the **+** button in the top right.
3. Paste the following URL:
   ```
   https://vkr1729.github.io/mindspace-source/apps.json
   ```
4. Or tap **[Add to SideStore (1-Tap)](https://vkr1729.github.io/mindspace-source/)** from Safari.
