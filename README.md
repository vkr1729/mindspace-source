# MindSpace iOS — Public Distribution Source

This repository contains only the public SideStore/AltStore metadata and unsigned release artifacts for MindSpace. It does not contain the private application source, meditation content, credentials, or personal data.

## Add to SideStore

Use this stable source URL:

```text
https://raw.githubusercontent.com/vkr1729/mindspace-source/main/apps.json
```

Or open the [one-tap SideStore link](sidestore://source?url=https://raw.githubusercontent.com/vkr1729/mindspace-source/main/apps.json) on the iPhone.
